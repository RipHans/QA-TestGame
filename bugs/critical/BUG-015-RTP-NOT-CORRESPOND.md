| Поле | Значение |
|---|---|
| Серьёзность | Критическая: владелец игры теряет деньги (финансовый баг) |
| Статус | Открыт, нужно подтвердить требования (см. "Примечания") |
| Компонент | серверная логика |
| Дата | 25.10.2026 |

## Примечания
- Сотреть README.md -> Открытые вопросы (первый пункт)
- На предпоследней строке в файле: % RTP без учета правила "пары справа платят". на маленьких количествах раундо может быть завышен, из-за возможных крупных выигрышей вроде пары семерок (платит 550)

## Окружение
- Игра: TestGame (https://gametests.nyc.wf)
- Браузер и ОС: Chrome 155.0.8059.85, Windows 11

## Предусловия
Установлен Python3.12+, скрипт и зависимости для него

## Шаги воспроизведения
1. Открыть папку с файлом main.py
2. Запустить его: `python main.py` (по желанию с флагами -r и/или -m по желанию)
3. Дождаться завершения работы скрипта
4. Проверить созданый лог файл 

## Альтернативные шаги воспроизведения
1. Открыть игру в браузере, записать стартоый баланс, убедиться что выбрано 5 линий и 1 ставка на линию
2. Нажать AUTO 1 раз или SPIN желаемое количество раундов
3. Посмотреть баланс после раундов, записать 
4. Вычесть стартовый баланс из итогового, поделить на (количество пройденых раундов * ставка (1*5)), умножить на 100.

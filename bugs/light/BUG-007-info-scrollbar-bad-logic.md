# BUG-007: Закрытие окна с информацией при взаимодействии со скроллбаром
| Поле | Значение |
|---|---|
| Серьёзность | Низкая: слегка портит UX |
| Статус | Открыт |
| Компонент | элементы интерфейса/frontend логика  |
| Дата | 24.10.2026 |

## Окружение
- Игра: TestGame (https://gametests.nyc.wf)
- Браузер и ОС: Chrome 155.0.8059.85, Windows 11

## Предусловия
Игра загружена

## Шаги воспроизведения
1. Открыть игру
2. Открыть окно с информацией (кнопка "i" в шапке страницы)
3. Потянуть скроллбар вниз мышью


## Ожидаемый результат
Окно информации прокручивается вслед за движением мыши

## Фактический результат
Окно с информацией закрывается

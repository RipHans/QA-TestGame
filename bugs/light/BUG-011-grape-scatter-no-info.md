# BUG-011: Незивестное значение scatter для винограда (в правилах не описано)

| Поле | Значение |
|---|---|
| Серьёзность | Низкая: неизвестное значение параметра scatter, на практике изменения в поведении замечено не было|
| Статус | Открыт |
| Компонент | Правила и тексты|
| Дата | 24.10.2026 |

## Окружение
- Игра: TestGame (https://gametests.nyc.wf)
- Браузер и ОС: Chrome 155.0.8059.85, Windows 11

## Предусловия
Игра загружена

## Шаги воспроизведения
1. Открыть игру
2. Открыть DevTools (F12) -> `Network` -> `Socket` -> `Messages`
3. Найти ответ сервера `"method"`: `"GET_DYNAMIC_HELP_INFO"` (обычно четвертый ответ от начала сессии)
4. Найти объект с полем "icon_number": 4 (виноград) — это 4-й элемент массива items. В его поле "wins" третий элемент содержит "is_scatter": true, "win": 40

## Ожидаемый результат
Неизвестно, в правилах не описано.

## Фактический результат
Не подтверждено (возможны баги)

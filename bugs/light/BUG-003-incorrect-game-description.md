# BUG-003: Неверное описание игры (5-reel, 10 playlines)

| Поле | Значение |
|---|---|
| Серьёзность | Низкая: неверное описание игры, не влияет на игровой процесс|
| Статус | Открыт |
| Компонент | Правила и тексты|
| Дата | 24.10.2026 |

## Окружение
- Игра: TestGame (https://gametests.nyc.wf)
- Браузер и ОС: Chrome 155.0.8059.85, Windows 11

## Предусловия
Игра загружена

## Шаги воспроизведения
1. Открыть игру
2. Открыть информацию (кнопка "i" в шапке страницы)
3. Пролистать вниз до блока RULES
4. Сравнить описание правил игры с раскладкой и блоком PAYLINES

## Ожидаемый результат
Согласно правилам "5-reel, 3-row slot game with 10 playlines" игрок ложен видеть игру с 5-барабанами, 10-рядами выплат

## Фактический результат
Игрок видит игру с тремя барабанами и пятью рядами выплат

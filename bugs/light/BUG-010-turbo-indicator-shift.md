# BUG-010: Сдвиг индикатора активности относительно кнопки TURBO
| Поле | Значение |
|---|---|
| Серьёзность | Низкая: слегка портит UI |
| Статус | Открыт |
| Компонент | элементы интерфейса/frontend логика  |
| Дата | 24.10.2026 |

## Окружение
- Игра: TestGame (https://gametests.nyc.wf)
- Браузер и ОС: Chrome 155.0.8059.85, Windows 11

## Предусловия
Игра загружена

## Шаги воспроизведения
1. Открыть игру
2. Нажать TURBO


## Ожидаемый результат
Индикатор активности становится красным

## Фактический результат
После задержки слева от неактивного индикатора появляется красный индикатор активности

# BUG-004: Опечатки в описании игры (Название) и таблице выплат (Вишни)
| Поле | Значение |
|---|---|
| Серьёзность | Низкая: опечатки, не влияет на игровой процесс |
| Статус | Открыт |
| Компонент | правила и тексты  |
| Дата | 24.10.2026 |

## Окружение
- Игра: TestGame (https://gametests.nyc.wf)
- Браузер и ОС: Chrome 155.0.8059.85, Windows 11

## Предусловия
Игра загружена

## Шаги воспроизведения
1. Открыть игру
2. Открыть информацию (кнопка "i" в шапке страницы)
3. Пролистать вниз до блока PAYTABLE
4. Посмотреть на максимально возможное количество вишен на линии
5. Сравникть с PAYLINES
6. Пролистать до блока RULES
7. Сравнить название игры с title на вкладке браузера

## Ожидаемый результат
Согласно названию в title игра должна называтьс TestGame.
Согласно PAYLINES макисмальное число символов на линии = 3. Cherry x3, x2

## Фактический результат
Игра назвается "This game is 3"
Возде вишен (Cherry) в PAYTABLE указано x4, x2

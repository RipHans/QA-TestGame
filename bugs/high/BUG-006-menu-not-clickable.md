# BUG-006: Некликабельная кнопка вызова меню
| Поле | Значение |
|---|---|
| Серьёзность | Высокая: дает плохой UX |
| Статус | Открыт |
| Компонент | элементы интерфейса/frontend логика  |
| Дата | 24.10.2026 |

## Примечание
Баг воспроизводится и на десктоп версии и на мобильной. Шаги воспроизведения одинаковы на обеих платформах

## Окружение
- Игра: TestGame (https://gametests.nyc.wf)
- Браузер и ОС: Chrome 155.0.8059.85, Windows 11
- Браузер и ОС: Chrome mobile, Android

## Предусловия
Игра загружена.

## Шаги воспроизведения
1. Открыть игру
2. Кликнуть по кнопке меню (кнопка Бургер с тремя полосками в нжнем левом углу окна игры)


## Ожидаемый результат
Согласно UI клик по кнопке должен открывать игровое меню

## Фактический результат
Ничего не происходит

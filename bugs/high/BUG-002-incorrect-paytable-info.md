# BUG-002: Некорректные значения в PAYTABLE (правила)

| Поле | Значение |
|---|---|
| Серьёзность | Высокая: игрок недополучает выигрыш |
| Статус | Открыт, нужно подтвердить требования (см. "Примечания") |
| Компонент | Правила и тексты (PAYTABLE)
| Дата | 24.10.2026 |

## Примечания
- Значения для колокольчика x2 (BELL: x2) и винограда x3 (GRAPE: x3) не совпадают с ответами сервера (GET_DYNAMIC_HELP_INFO). Если в таблице актуальные значения, это баг в логике, не в интерфейсе. В тестах ответы сервера взяты как истинные.

## Окружение
- Игра: TestGame (https://gametests.nyc.wf)
- Браузер и ОС: Chrome 155.0.8059.85, Windows 11
- Настройки: LINES 5, BET 5 на экране (`bet_per_line` = 1), COIN VALUE $1 000 (`denom` = 1000)

## Предусловия
Игра загружена, на балансе достаточно средств, включены все 5 линий.


## Шаги воспроизведения для BELL x2
1. Открыть игру и убедиться, что LINES = 5 и BET = 5.
2. Нажимать SPIN, пока на какой-либо линии не выпадет пара колокольчиков на двух левых барабанах при другом символе на правом. Пример: линия 2 (верхняя гризонталь левый -> правый), колокольчик, колокольчик, лимон.
3. Дождаться остановки барабанов и посмотреть выигрыш и баланс, сравнить с таблицой выплат (PAYTABLE)

## Ожидаемый результат для BELL x2
Согласно таблице выплат PAYTABLE (2 колокольчика) спин выигрывает 60 кредитов при bet_per_line = 1, то есть +60 000 к балансу при denom = 1000.

## Фактический результат для BELL x2
Начислено 50 кредитов при bet_per_line = 1, то есть +50 000 к балансу при denom = 1000.


## Шаги воспроизведения для GRAPE x3
1. Открыть игру и убедиться, что LINES = 5 и BET = 5.
2. Нажимать SPIN, пока на какой-либо линии не выпадет три винограда. Пример: линия 1 (средняя гризонталь), виноград, виноград, виноград.
3. Дождаться остановки барабанов и посмотреть выигрыш и баланс, сравнить с таблицой выплат (PAYTABLE)

## Ожидаемый результат для GRAPE x3
Согласно таблице выплат PAYTABLE (3 винограда) спин выигрывает 60 кредитов при bet_per_line = 1, то есть +60 000 к балансу при denom = 1000.

## Фактический результат для GRAPE x3
Начислено 40 кредитов при bet_per_line = 1, то есть +40 000 к балансу при denom = 1000.


## Доказательства
Ответ сервера (GET_DYNAMIC_HELP_INFO) payload -> items -> (2, 3) -> wins.

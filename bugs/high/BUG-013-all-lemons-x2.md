# BUG-013: При выпадении лимонов на каждой payline так же выигрыш удваивается.
| Поле | Значение |
|---|---|
| Серьёзность | Высокая: Владелец игры теряет деньги (см. "Примечания") |
| Статус | Открыт |
| Компонент | элементы интерфейса/frontend логика  |
| Дата | 24.10.2026 |

## Примечания
- Правила в PAYTABLE не совпадают ответами сервера: в правилах выигрых удваивается только для винограда, вишни, сливы. Прошу уточнить ожидаемое поведение. Если выигрыш должен удваиваться для любого символа, которым заполнены все линии, то это недосказанность правил, а не баг логики.
- В таком случае серьезность бага низкая.

## Окружение
- Игра: TestGame (https://gametests.nyc.wf)
- Браузер и ОС: Chrome, Android

## Предусловия
Игра загружена, на балансе достаточно средств, включены все 5 линий, `bet_per_line = 1`, `denom (coin value = 1$)`.

## Шаги воспроизведения
1. Открыть игру
2. Нажимать SPIN (ее альтернативу для мобильной версии) пока всё поле не будет заполнено лимонами
3. Сравнить ожидаемый и фактический результат.


## Ожидаемый результат
+ 200 кредитов к балансу при (`lines = 5`, `bet_per_line = 1`, `denom (coin value = 1$)`)

## Фактический результат
+ 400 кредитов к балансу при (`lines = 5`, `bet_per_line = 1`, `denom (coin value = 1$)`)

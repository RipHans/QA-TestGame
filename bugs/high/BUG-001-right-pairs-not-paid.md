# BUG-001: Пара одинаковых символов справа налево не оплачивается

| Поле | Значение |
|---|---|
| Серьёзность | Высокая: игрок не получает положенный выигрыш |
| Статус | Открыт, нужно подтвердить требования (см. "Примечания") |
| Компонент | Расчёт выигрыша (серверная логика) |
| Дата | 24.10.2026 |

## Примечания
- Текст правил в игре не совпадает с ответами сервера: в нём "starting from the leftmost or from the rightmost". Возможно, "rightmost" к этой игре не относится (см. [BUG-004]). Прошу уточнить ожидаемое поведение. Если справа налево оплачиваться не должно, это опечатка правил, а не баг логики.

## Окружение
- Игра: TestGame (https://gametests.nyc.wf)
- Браузер и ОС: Chrome 155.0.8059.85, Windows 11
- Настройки: LINES 5, BET 5 на экране (`bet_per_line` = 1), COIN VALUE $1 (`denom` = 1)

## Предусловия
Игра загружена, на балансе достаточно средств, включены все 5 линий.

## Шаги воспроизведения
1. Открыть игру и убедиться, что LINES = 5 и BET = 5, COIN VALUE $1
2. Нажимать SPIN, пока на какой-либо линии не выпадет пара одинаковых символов на двух правых барабанах при другом символе на левом. Пример: два винограда справа.
3. Дождаться остановки барабанов и посмотреть выигрыш и баланс.
4. Для доказательства: DevTools -> Network -> Socket -> Messages, найти ответ на `START_GAME` этого спина.

## Альтернативные шагр воспроизведения
1. Открыть папку с файлом main.py
2. Запустить его: `python main.py -r 2000 -m`
3. Дождаться завершения работы скрипта
4. Проверить созданый лог файл 

## Ожидаемый результат
По правилам ("starting from the leftmost or from the rightmost") и PAYTABLE (2 винограда) спин выигрывает 30 кредитов при `bet_per_line` = 1, то есть +30 к балансу при `denom` = 1.

Источники: текст RULES и PAYTABLE (скриншоты), `GET_DYNAMIC_HELP_INFO`, символ 4 (виноград): 2 символа = 30.

## Фактический результат
Выигрыш не начислен, списана только ставка (5). Баланс после спина

Пример из лога:

27-10-2026_06-42-01  | MISMATCH | round=278  | bet=1x5     | server=30.0  | model=33.0  | drum=[[4, 3, 5], [4, 2, 8], [7, 8, 8]] - не оплачена комбинация из 2 BAR справа

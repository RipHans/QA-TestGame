# BUG-012: Переключение режима игры есть только на мобильных устройствах
| Поле | Значение |
|---|---|
| Серьёзность | Высокая: игрок на ПК не может переключить режим игры |
| Статус | Открыт |
| Компонент | элементы интерфейса/frontend логика  |
| Дата | 24.10.2026 |

## Окружение
- Игра: TestGame (https://gametests.nyc.wf)
- Браузер и ОС: Chrome, Android

## Предусловия
Игра загружена

## Шаги воспроизведения
1. Открыть игру
2. Найти кнопку в виде фишки
3. Убедиться в её работоспособности. (на мобильной версии протестиовано, кнопка работает)
4. Открыть меню Chrome (три вертикальные точки справа от строки поиска)
5. Проскроллить вниз и выбрать версию для ПК (значек компьютера)
6. Сравнить UI с мобильной версией


## Ожидаемый результат
UI мобильной и пк версии не отличается по функционалу. Кнопка изменения режима игры присутствует везде

## Фактический результат
В ПК версии приложения кнопка для изменения режима игры не отображается

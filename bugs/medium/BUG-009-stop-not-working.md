# BUG-009: STOP в режиме AUTO не останавливает режим
| Поле | Значение |
|---|---|
| Серьёзность | Средняя: портит UX |
| Статус | Открыт |
| Компонент | элементы интерфейса/frontend логика  |
| Дата | 24.10.2026 |


## Окружение
- Игра: TestGame (https://gametests.nyc.wf)
- Браузер и ОС: Chrome 155.0.8059.85, Windows 11

## Предусловия
Игра загружена, на балансе достаточно средств.

## Шаги воспроизведения (Кейс №1)
1. Открыть игру.
2. Нажать AUTO.
3. Нажать STOP.

## Ожидаемый результат
Остановка автоматического режима игры

## Фактический результат 
Интерфейс не реагирует на нажатие, автоматическая игра продолжается.

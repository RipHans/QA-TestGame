# BUG-016: Кнопка "i" в мобильной версии находится фактически выше, чем ее визуал
| Поле | Значение |
|---|---|
| Серьёзность | Средняя: портит UX |
| Статус | Открыт |
| Компонент | элементы интерфейса/frontend логика  |
| Дата | 24.10.2026 |

## Примечание
Полагаю под визуалом кнопки информации находится прозрачная кнопка "Открыть в полноэкранном режиме"


## Окружение
- Игра: TestGame (https://gametests.nyc.wf)
- Браузер и ОС: Chrome mobile, Android

## Предусловия
Игра загружена.

## Шаги воспроизведения
1. Открыть игру
2. Кликнуть по кнопке "i" (кнопка верхнем левом углу окна игры)


## Ожидаемый результат
Согласно UI клик по кнопке должен открывать информацию/правила игры

## Фактический результат
Игра открывается в полноэкранном режиме без рамок. Информация/правила игры не открываются

## Доказательства
Баг проявляется как разница между зоной клика и видимым расположением кнопки. Скриншот не показывает кликабельную область, только визуал. Подтверждается многократным повторением клика в одном и том же месте

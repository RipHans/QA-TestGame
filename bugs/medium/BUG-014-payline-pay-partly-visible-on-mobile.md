# BUG-014: Выигрыш на линии выплаты на мобильных устройствах виден только частично
| Поле | Значение |
|---|---|
| Серьёзность | Средняя: игрок не видит сколько платит линия в случае выигрыша |
| Статус | Открыт |
| Компонент | элементы интерфейса/frontend логика  |
| Дата | 24.10.2026 |

## Окружение
- Игра: TestGame (https://gametests.nyc.wf)
- Браузер и ОС: Chrome mobile, Android

## Предусловия
Игра загружена, на балансе достаточно средств.

## Шаги воспроизведения
1. Открыть игру
2. Нажимать SPIN (aналог на мобильной версии) пока на какой либо линии не выпадет выигрышная комбинация.
3. Посмотреть слева от линии выплаты, сколько платит комбинация


## Ожидаемый результат
Выигрыш слева от линии выплаты виден полностью.

## Фактический результат
Выигрыш слева от линии выплаты виден только частично/не виден вовсе.

# BUG-005: Некликабельная кнопка для выключения звуков в игре
| Поле | Значение |
|---|---|
| Серьёзность | Средняя: может влиять на комфортный игровой процесс |
| Статус | Открыт |
| Компонент | элементы интерфейса/frontend логика  |
| Дата | 24.10.2026 |

## Окружение
- Игра: TestGame (https://gametests.nyc.wf)
- Браузер и ОС: Chrome 155.0.8059.85, Windows 11

## Предусловия
Игра загружена

## Шаги воспроизведения
1. Открыть игру
2. Кликнуть по кнопке с иконкой динамика
3. Кликнуть "SPIN"


## Ожидаемый результат
Согласно UI клик по кнопке должен выключать/регулировать звук в игре

## Фактический результат
Игра продолжает проигрывать звуки при взаимодействии.
